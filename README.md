# English Writing Studio

English Writing Studio is a lightweight, privacy-focused web application designed to help users practice English writing at their own pace without the pressure of creating an account or logging in. 

Live Demo: https://abhimanukd.github.io/akdenglish/

---

## 🚀 Features

- **No Login, No Pressure:** Start practicing instantly. No account creation or personal data collection required.
- **Learning Path:** Structured progression or guided modules to improve your grammar, vocabulary, and sentence composition.
- **My Writing Progress:** Locally tracks your achievements, practice consistency, and writing milestones.
- **Dark Mode Support:** Built-in theme toggling for comfortable writing sessions at any time of day.
- **Clean UI:** Minimalist and clutter-free interface designed to maximize focus and minimize distractions.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla / ES6+)
- **Hosting:** GitHub Pages

## 🔧 Local Development

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project directory:**
   ```bash
   cd akdenglish
   ```

3. **Open the project:**
   Simply open `index.html` in your preferred web browser, or use a local development server like Live Server in VS Code.
